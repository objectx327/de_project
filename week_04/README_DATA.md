# Данные к домашнему заданию недели 4

Распакуйте архив в отдельную папку `week_04/` своего учебного репозитория.
Все данные вымышлены. Подробные правила и задания находятся в `DE_4_homework.pdf`.
Исходные файлы сохраняйте без исправлений. Скрипты обработки напишите самостоятельно.

## Платежи

CSV: UTF-8 без BOM, разделитель `;`, кавычки `"`. Заголовок обязателен.
В одном комментарии есть перенос строки: число физических строк не равно числу записей.

| Файл | Записей | Назначение |
| --- | ---: | --- |
| `payments_day1.csv` | 100 | Первая загрузка: 98 принятых и 2 отклонённых |
| `payments_quality.csv` | 20 | Проверки качества: 4 принятых и 16 отклонённых; загрузка запрещена |
| `payments_delta.csv` | 5 | Два уже известных платежа и три новых |
| `payments_conflict.csv` | 2 | Изменённое время известного платежа и новый платёж |
| `payments_rollback.csv` | 3 | Проверка отката между порциями |

## Заказы

`orders.json`: пять заказов, включая один с пустым items.
`orders_stream.jsonl`: те же пять корректных заказов, четыре ошибочные записи
и одна пустая физическая строка. Разбирать файл нужно построчно.
Данные заказов обрабатываются отдельно и не загружаются в таблицу платежей.

## Негативные сценарии

В `data/raw/fixtures/` находятся намеренно повреждённые CSV и JSON.
`empty.csv` имеет размер 0 байт; `invalid_utf8.csv` специально содержит
недопустимые байты UTF-8. Не пересохраняйте их в редакторе перед проверкой.

## PostgreSQL

Выполните `sql/00_setup.sql` один раз в учебной базе. Таблица изначально пустая.
Для заданий 4-6 порядок запусков указан в PDF. Не очищайте таблицу между ними.
Пакет не содержит паролей, готового загрузчика или решений заданий.
